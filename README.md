# Derin Öğrenme Ödev Sistemi

[Öğrenci girişi](https://fikrigokpinar.github.io/derinogrenme-odev/) · [Öğretmen paneli](https://fikrigokpinar.github.io/derinogrenme-odev/teacher/)

Bu depo yalnızca yayımlanabilir arayüzü ve tarayıcıda kod çalıştırmak için gereken dosyaları içerir. Öğrenci kayıtları ve gönderimler yetkilendirilmiş Supabase hizmetinde tutulur. Çözümler, cevap anahtarları ve onaylanmamış ders notları bu depoya dahil değildir.

Python/PyTorch kodu öğrencinin tarayıcısında Pyodide ile çalışır. Giriş ve gönderim işlemleri internet bağlantısı gerektirir.
